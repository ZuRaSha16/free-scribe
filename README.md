# Free Scribe 

Free Scribe is a powerful web app that converts speech into text and translates it into any language. Users can upload audio files or record their voice in real time, and the app will transcribe the speech with high accuracy. With built-in translation features, Free Scribe makes it easy to convert text into different languages, breaking language barriers effortlessly.

🔹 Features: <br>
✔️ Upload or record audio for transcription<br>
✔️ Accurate speech-to-text conversion<br>
✔️ Translate text into multiple languages<br>
✔️ User-friendly and efficient<br>
